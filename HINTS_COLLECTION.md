# Wasgij official hints and image links

This is a **links-only** index of official Wasgij resources. No third-party images are copied into this repository.

## Browse official resources

- [Wasgij puzzles and hints archive](https://wasgij.com/collections/archive)

## Matching rules

- Match owned puzzles by **series + number + piece count** against `inventory.csv`.
- Keep 150-piece editions, collector's boxes and distinct piece counts separate.
- Record only **verified** individual puzzle and hint URLs. Do not construct URLs from titles.
- Prefer owned puzzles first when reviewing new links, then expand to unowned `catalogue.csv` entries.
- Link directly to official resources rather than embedding or copying images.
- Leave unavailable links blank and mark the verification status in `hints.csv`.

## Coverage status

The official archive index has been verified. Individual puzzle and hint links remain to be verified; the current index is a scaffold rather than a claim that all hints have been discovered.

See [`hints.csv`](hints.csv) for the link register.
